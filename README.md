# dino — 终端小恐龙跑酷

Chrome 小恐龙的原创致敬实现：纯 Python 标准库，无第三方依赖。

## 玩法

恐龙自动向右奔跑，玩家控制跳跃与低头躲避障碍物：

- `j` 跳跃 —— 躲开仙人掌和低飞的鸟
- `d` 低头 —— 躲开高飞的鸟（低头时身高减半）
- `s` 站起，`q` 退出

障碍物：小/高/宽三种仙人掌（必须跳过）、低飞鸟（跳过）、高飞鸟（低头躲过）。
速度随得分提高而增加（每 400 分提一档，上限 3.0）。

## 用法

```bash
python3 -m dino                  # 交互模式（需要终端）
python3 -m dino --auto           # 无头自动演示：AI 自动跳/躲
python3 -m dino --auto --frames 500 --seed 42
python3 -m dino --auto --verbose # 每 100 帧打印一次画面
```

交互模式通过管道输入命令，例如：`printf 'j\nj\nd\ns\nq\n' | python3 -m dino`。

## 设计取舍

- 跳跃物理为简化模型（初速 2.0、重力 0.5，顶点约 5 格、滞空约 8 帧），
  手感接近原版但数值是独立调校的。
- `--auto` 的 AI 是简单规则（按"滞空时间 × 速度"提前起跳），只做演示与回归，
  不是最优玩家；连续障碍等极端情况可能失误。
- 无实时键盘输入：交互为"每行一个命令"的回合制，这是小巧取舍，
  不是实时动作游戏。

## 验证记录（真实运行）

- `python3 -m py_compile dino.py __main__.py` 通过
- 单元测试：跳跃弧线（顶点 5.0 格、必落地）、仙人掌碰撞致死、
  低头躲高飞鸟、低飞鸟撞站立恐龙、跳过高仙人掌、速度 1.0→1.5→3.0 递增、
  碰撞盒相交判定 —— 全部通过
- `--auto --frames 1000` 在 seed 42/1/7/99/123 下全部跑满 1000 帧无崩溃

## 已知局限

- 无实时键盘操作（curses 实时模式不在小巧范围内）
- 无最高分存档、无难度分级选项
- AI 演示不代表人类可达水平；障碍物间距随机，偶发"无解"组合时 AI 会如实撞毁
